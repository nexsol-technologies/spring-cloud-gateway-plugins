Scroll to zoom, drag to pan, drag a node to move it. Click a node to focus it and its neighbours, click it again to come back. An arrow goes from the caller to what it reached; it thickens with the number of calls and reddens with the share that failed. The graph is refreshed on demand, never on a timer, so a layout you are reading does not move under you.
The gateway itself is not a node: it sits on every edge, which is what lets it count them. A caller it could not name — no client claim in a token, no caller header — is drawn as unknown.
